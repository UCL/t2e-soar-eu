# Atlas Research Paper

This directory contains the manuscript and reproducible figure-generation code for the Atlas paper, submitted to *Computers, Environment and Urban Systems*.

The paper presents a morphological typology of 626 European cities based on the SOAR-EU dataset, organised around three axes (Intensity, Continuity, Irregularity) that define eight urban types.

## Manuscript

- `atlas.tex` — main manuscript
- `atlas_macros.tex` — auto-generated LaTeX macros (produced by `code/generate_macros.py`)
- `atlas_overrides.tex` — style overrides

The bibliography is embedded in `atlas.tex` via `\begin{thebibliography}` (LaTeX does not read an external `.bib` file for this project).

Compile with: `latexmk -pdf atlas.tex`

## Reproducing figures

All plate scripts are standalone. Run from the repo root:

```bash
cd paper_research/code && uv run python plate1_exemplars.py
```

Scripts follow the naming convention `plate{N}_{name}.py` (plates 1–12, with plates 2 and 3 generated by `plate2_3_ripples_lines.py`).

### Shared modules

- `atlas_common.py` — centralised sizing constants, colours, symbol helpers, positioning functions
- `shared_config.py` — metric column definitions, labels, axis configuration, city data loader
- `cache_city_data.py` — utility for populating the shared parquet cache from processed GeoPackages

### Other utilities

- `generate_macros.py` — generates `atlas_macros.tex` from metric data
- `extract_numbers.py` — extracts computed statistics for inline citations
- `download_satellite_tiles.py` — downloads exemplar satellite imagery from Esri World Imagery
- `analysis_morphology_vs_density.py` — multilevel decomposition of form, density, and access (backs the analytical appendix)
- `supplement_figures.py` — generates supplementary tables and the dose-response figure
- `atlas_figures/frontage_validation.py` — generates the frontage validation figure cited in the appendix

## Outputs

Figures are written to `outputs/atlas/`:

- `plate{N}_*.{pdf,png}` — the twelve plates
- `plate4_buildings_full.pdf` — full 626-city supplement version of Plate 4
- `satellites/` — per-type exemplar satellite imagery used by Plate 1
- `supplement/` — analytical supplement tables (variance decomposition, marginal contributions, matched pairs) and the dose-response figure
- `validation/frontage_validation.pdf` — street-frontage ratio validation figure
